# Streamlit Dashboard

The Bank Churn Prediction project includes an interactive **Streamlit + Plotly dashboard** for exploring customer churn, analyzing customer risk, and predicting churn for a new customer.

The dashboard uses the trained Machine Learning model and processed prediction data generated by the main pipeline.

---

## Dashboard Technology

- **Framework:** Streamlit
- **Visualization:** Plotly
- **Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Model Loading:** Joblib

---

## Dashboard Features

### 1. Executive Overview

The dashboard provides an overview of the bank's customer churn data.

It includes:

- Total number of customers
- Churn-related summary information
- Risk tier distribution
- Churn probability analysis
- Customer-level data overview

---

### 2. Churn Probability Analysis

The dashboard visualizes customer churn probabilities generated by the trained Machine Learning model.

The analysis helps identify:

- Customers with low churn probability
- Customers with medium churn probability
- Customers with high churn probability
- Customers with critical churn probability

A probability histogram is provided to understand the overall distribution of customer churn risk.

---

### 3. Numeric Feature Analysis

The dashboard provides interactive analysis of important numeric customer features.

Examples include:

- Credit Score
- Age
- Tenure
- Balance
- Number of Products
- Estimated Salary

These features can be explored to understand their relationship with customer churn and risk.

---

### 4. Customer Prediction

The dashboard allows the user to enter details for an individual customer and generate a churn prediction using the trained Random Forest model.

### Input Features

The prediction form accepts:

- Credit Score
- Geography
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Has Credit Card
