# Reports

`Final_Report.docx` / `Final_Report.pdf` are written deliverables, not
generated by the pipeline itself — build them from the pipeline's real
outputs once you've run `python main.py` on your actual data. Suggested
outline:

1. **Executive Summary** — overall churn rate, top 3 churn drivers, headline recommendation
2. **Data Overview** — source, size, cleaning steps (`data/processed/cleaned_data.csv`)
3. **Exploratory Findings** — embed `images/graphs/01_churn_distribution.png` through `04_correlation_heatmap.png`; call out churn rate by Geography, NumOfProducts, IsActiveMember
4. **Model & Methodology** — algorithms compared, SMOTE rebalancing, hyperparameter tuning, chosen decision threshold (see `README.md` → "Modeling Approach")
5. **Model Performance** — embed `05_roc_curve.png`, `06_confusion_matrix.png`, `07_feature_importance.png`; report ROC-AUC / F1 / precision / recall from the `train_model.py` log output
6. **Risk Segmentation & Business Impact** — risk tier breakdown, total estimated value at risk (from `data/processed/predictions.csv`)
7. **Recommendations** — retention actions per tier, referencing `data/processed/retention_worklist_top100.csv`

Ask Claude to generate `Final_Report.docx` directly from your run's
actual numbers and plots once you have them — it can build a fully
formatted Word document from this outline.
